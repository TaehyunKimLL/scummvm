# DOS 포트 M5 — SCUMM (Monkey Island 1/2) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 같은 DOS 백엔드로 SCUMM 엔진만 넣은 두 번째 실행 파일 `SCUMM.EXE` 를 만들어, Monkey Island 1(DUMB 한국어 EUC-KR 패치: L·U·패치 폰트 모드)과
Monkey Island 2(영어, 한국어 L·U — `korean.trs`)가 DOSBox-X·Staging(memsize 16)에서 로딩 화면 → 제목 → 첫 장면 → 대사까지 가고, 캡처가 리눅스 기준과
바이트 단위로 같으며, 음악이 OPL/MT-32 로 나온다. 한국어 얼굴은 charset 마다 비교 시트를 보고 사용자가 고르고, 게임별 부분 집합 SVF 로 굽는다. MI1·MI2 zip 을 낸다.

**Architecture:** 백엔드는 그대로 쓰고(`backends/platform/dos`), `build-dos.sh` 가 엔진 판(`sci`/`scumm`)을 받아 다른 출력 디렉터리에 빌드한다. 두 EXE 는
`SCUMMVM.INI`/`SCUMMVM.LOG` 를 같이 쓴다. SCUMM 쪽에는 SCI 선례를 따른 디버그 소켓 확장(`state`/`wait`/`freeze`/`run`/`dump`)을 범용 기능으로 더한다 —
SCUMM 루프는 `delta = VAR_TIMER_NEXT` 로 결정적이므로 동결 상태에서만 입력을 넣으면 리눅스와 DOS 가 같은 루프에서 같은 상태가 된다. 한국어 텍스트는
SCUMM hi-res 텍스트 층(scale 2 → 640×400, L=CLUT8 1bpp, U=맵 `alpha=true` → XRGB8888 2bpp)이 charset 마다 `[font.N] bitmap=` SVF 로 그린다.

**Tech Stack:** DJGPP 12.2 + SDL3 DOS, ScummVM i18n (engines/scumm, graphics/hires_text, gui/debugsocket), iMUSE + `dosopl`/MPU-401, Python 3 + Pillow
(`tools/korean/mkfont.py`, 하네스), CxxTest, DOSBox-X 2026.08 / Staging 0.83.

**Spec:** `docs/superpowers/specs/2026-09-28-scummvm-dos-sdl3-design.md` (원칙 1–4, §3.5, §4, §5, §7, §8) +
`docs/superpowers/specs/2026-09-29-dos-m5-scumm-addendum.md` (M5 결정·사실·수락 기준 A1–A13 — 이 계획의 판정 기준은 전부 거기 있다)
